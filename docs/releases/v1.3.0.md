## Serial Link Tester v1.3.0

A portable Windows GUI for serial link integrity, throughput, latency and jitter
testing, with a dark English interface and simultaneous bidirectional traffic.

### Features

- One-way, simultaneous bidirectional and external-loopback round-trip setups.
- Selectable/custom baud rate, payload, duration and target load per direction.
- Independent loss, corruption, goodput, delay and jitter results for both directions.
- Live charts and HTML, CSV and JSON exports.
- Named non-fatal Framing, Break, Overrun, RX overflow and Parity warnings;
  test-stopping errors are shown separately.
- Default bidirectional setup and a one-second final receive window.
- Built-in simulated demo and a custom application icon.

Requires Windows 10/11, .NET Framework 4.x and the serial adapter's driver.
Both directions must be wired and support simultaneous traffic for bidirectional tests.

### Validation and scope

30 automated software tests cover integrity, measurement accounting, concurrency,
shutdown, warning/error handling and exports. The hardware transport in these tests
is simulated. Timing includes Windows, driver/adapter buffering, UART serialization
and the tested link; the application does not supply hardware timestamps or raw BER.

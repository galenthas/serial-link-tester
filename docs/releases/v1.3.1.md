## Serial Link Tester v1.3.1

The Details report now keeps your scroll position and text selection while a test
is running. You can read the latency, transfer and event sections without being
sent back to the top on each refresh.

- Scroll position is retained when changing direction or returning from another tab.
- New events do not move the current view; scroll down to read them.
- Starting a new test still clears the report and returns to the top.
- Baud settings, traffic generation, measurements and exported report formats are unchanged.

### Validation

30 core tests and 7 Windows UI tests pass locally. UI coverage includes repeated
updates, appended events, text selection, hidden tabs, shorter reports, direction
changes and a bidirectional demo through completion and restart. Transport tests
and the demo are simulated; no new physical serial-link validation is claimed.

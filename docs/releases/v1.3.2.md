## Serial Port Tester v1.3.2

Serial Link Tester is now Serial Port Tester. Run `SerialPortTester.exe`
or extract `SerialPortTester_v1.3.2_Windows.zip` for the guides and license.

The demo has been removed. Connect a serial port to run a test.

The main window opens directly on the test settings and connection path. The
application name appears in the title bar.

The six measurement cards now use fewer columns on narrow windows. Each row
allows enough height for its title, value and wrapped description. Scroll the
results pane on short screens to reach the chart or report.

This build also includes the live Details scroll fix from v1.3.1.

The Windows layout test checks four window sizes with metric label fonts at
100%, 125% and 150% of their normal size. It checks for overlap, clipped text,
access to the report and retention of the dashboard scroll position during updates.
